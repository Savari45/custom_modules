Customer Required in POS

Enhance your Odoo v18 Point of Sale experience with our custom module that requires customer selection before payment.

Overview

  • This custom module for Odoo v18 enhances the Point of Sale (POS) system by making it compulsory to select a customer before proceeding to the payment screen.

    • Mandatory Customer Selection

  • Users must select a customer before they can proceed to payment.

    • Pop-up Notification

  • If no customer is selected, a pop-up will prompt the user to choose one.

    • Seamless Redirection

  • After selecting a customer, the system automatically redirects to the payment screen for efficient processing.

    • No Customer Changes on Payment Screen

  • Once a customer is selected, they cannot be changed from the payment screen, maintaining data consistency.
